## 2. Nutrition data

**Db.csv columns:** `food_code, food_name, energy_kj, energy_kcal, carb_g, protein_g, fat_g, fibre_g` (all per 100 g).

Quality checks (computed in `notebooks/VYNDRA_analytics.ipynb`): no missing values, no duplicate names; kJ/kcal ratio between 3.40 and 4.29; 973 of 1,014 foods (95.96%) are within 10% of the simplified Atwater estimate 4·protein + 4·carbs + 9·fat. The largest deviations are soups, where the table's energy is much lower than the macros imply.

**Serving data (workbook columns `servings_unit`, `unit_serving_energy_kcal`, …):** grams per serving are estimated as `unit_serving_energy_kcal / energy_kcal × 100`. An estimate is *valid* if a serving unit exists and the result is 5–1,000 g (907 of 1,014 valid); otherwise the API uses a flagged 100 g default.

**Selective_Diet_Mapping.csv columns:** `food_name, diet_tags, mood_tags, allergens, best_time_to_eat, description`. These tags drive diet-fit scores and allergen warnings, so they must be presented as guidance only.

## 6. Class maps and manifests (reviewed, human-made)

| File | Columns | Meaning |
|---|---|---|
| `classes.txt` | one class per line | The 220 class names stored in `best.pt` |
| `class_to_food_review.csv` | `class_name, suggested_food, similarity, status` | Generated suggestions (`needs_review` 165, `no_match` 29, `exact_text_review_required` 26). **Not approved.** |
| `class_to_food.csv` | `class_name, food_name, match_type` | **Approved** mapping, 115 rows (32 `exact`, 83 `family`). `none` = no equivalent. **Preserve it.** |
| `image_class_map_review.csv` | `dataset, dataset_class, best_pt_class, similarity, status` | Fuzzy suggestions for the 80 Kaggle folders |
| `image_class_map.csv` | `… , status, mapping_basis` | Kaggle → model class; only `status=ok` rows are used (9 ok / 71 skip) |
| `khana_class_map.csv`, `food101_class_map.csv` | `dataset, dataset_class, best_pt_class, accepted_model_classes, match_type, status` | Reviewed maps for 15 Khana and 10 Food-101 classes |
| `vision_test_manifest.csv` | `dataset, dataset_class, model_class, accepted_model_classes, match_type, relative_path, seed` | 690 rows: 240 Kaggle (8 classes) + 450 Khana (15 classes), 30 images per class |
| `reference_meals_template.csv` | `meal_id, food_name, reference_grams, reference_calories, notes` | Template for weighed-meal portion evaluation (only an example row today) |

**Eligibility rule:** only rows with `status=ok` and `match_type` of `exact` or `family`, whose model class is approved in `class_to_food.csv`, are counted as evaluation examples. **Fuzzy suggestions are not ground truth.**

`accepted_model_classes` lets one dataset class accept several equivalent model labels, separated by `|` (for example `chappati|roti|phulka`). The evaluation reports both accepted-class and primary-label accuracy. The Kaggle `aloo_gobi` folder is mapped to the classifier label `allo gobi` at manifest-build time; this does not change `class_to_food.csv`.
